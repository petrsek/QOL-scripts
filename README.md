# QOL-scripts
Quality of life scripts is a repository of random scripts and small apps I made to make my everyday life easier. 

System specific scripts are created for Linux (Pop!_OS).

## Installation

Each app is in a specific folder. Run ./install from the app's folder to install it (and ./uninst to uninstall). 

It is crucial for installing and uninstalling that the working directory is the same as the instal/uninstall script's.
