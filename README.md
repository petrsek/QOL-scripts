# QOL-scripts
Quality of life scripts is a repository of random scripts and small apps I made to make my everyday life easier. 

System specific scripts are usually created for Linux (Pop!_OS).

## Installation

There are "install" and "uninst" script in the root folder of this repo. The install script installs all installable apps with my prefered config. If you wish to install specific config, you must install the apps by their own scripts. The uninst script removes all apps.

Each app is in a specific folder. Run ./install from the app's folder to install it (and ./uninst to uninstall). Their own READMEs will tell you more details. Uninstall script expects default locations, if you modify install locations, uninstall manually.

It is crucial for installing and uninstalling that the working directory is the same as the instal/uninstall script's.
